    COLLECTION COVERAGE
    A much bigger library.
    The full public default pack is included in the ZIP, unchanged. The editor adds live-client / BloxdHub mappings and newer public assets, plus extracted model images and explicitly tinted variants. This is not a claim to include every private skin or unpublished game asset.
    Entries without a published graphic
    Internal states and partial blocks are available through search or “States / internal”. Doors, beds and similar multi-block objects include separate part states. Shapes and transparent / animated materials are editor renderings—not the full game’s physics or gameplay.
    

    YOUR LITTLE ANIMATION STUDIO
    Build. Pose. Action.
    1. Build a scene. Choose a block, then use Place (B) or Remove (X). Click a block in Select mode (V) to edit it individually. E shows colored rotation rings; Delete removes the selection.
    2. Pose Bob. Click a body part to rotate it directly, or use Whole player to turn the entire character. Held item selects the pickaxe separately. Motion between poses defaults to the shortest rotation, not the direction you dragged. Enable Full spins only for intentional turns. W / E / R show move, rotate and scale handles. Use the +90° buttons for quick turns.
    3. Make it move. Choose a time (or type it in the Time field), rotate or move your selection, then click Apply pose / transform. You can also edit first: unapplied changes stay while choosing the time. A first key after 0 seconds automatically adds the original starting pose. From start previews the whole clip. Revert edit cancels an unapplied change. This works for blocks, items, players, body parts and held tools.
    4. Light & export. Drag the sun in the Light tab. Export PNG or MP3 audio, or Render video and then click the retained Download MP4 / WebM button. The audio track can use the built-in synthesized effects or your own local file. MP3 does not contain video. Save a project JSON to keep your work.
    5. Gemini director. Use the Gemini button, enter your own key, describe the animation and Generate plan. Review the commands before Apply. A single Undo restores the previous scene. AI generation needs internet; manual editing remains offline.
    About the assets
    The full public default texture/model pack is included. Blocks, item names, face mappings and states are cross-referenced with the official Code API, BloxdHub and the public game client. The original equipment set keeps its corrected pixel-sprite geometry. Other assets use source models or catalog-based block shapes, with derived tints and unavailable entries labeled in Coverage. Bob’s classic red hoodie skin and editable rig are a reference-based recreation, not a verified original model. This is an unofficial fan-made editor.
    Default asset pack ↗ Bob reference ↗
    Imports: self-contained GLB (with textures/animations), OBJ geometry, STL and PLY, plus Bloxd schematics (.json) that become editable terrain blocks. Compressed GLB and external OBJ materials are not supported. Models stay local in your browser. Source assets retain their owners’ rights; no blanket redistribution license is implied.
    MP3 encoding uses lamejs 1.2.1 by Alex Zhukov and LAME, under the LGPL. Video export uses Mediabunny 1.62.1 (MPL-2.0) with browser-native encoders. Full licenses, upstream sources and rebuildable editor sources are included in the source bundle.
